## 📖 À propos du projet

**Eliano Prime Print** est une application web moderne conçue pour valoriser le savoir-faire d'un atelier créatif spécialisé dans le design graphique et l'impression publicitaire sur mesure. 

L'objectif de cette plateforme est d'offrir une vitrine élégante, rapide et orientée conversion, permettant aux clients (entreprises, créateurs, particuliers) d'explorer les réalisations de l'atelier et de commander ou demander un devis en quelques clics via WhatsApp.

---

## 🌟 Fonctionnalités clés

- **🎨 Portfolio interactif multi-catégories** :
  - Textiles & T-shirts personnalisés (DTF, flocage, broderie)
  - Affiches publicitaires & Bâches grand format
  - Tableaux décoratifs sur toile canvas moderne
  - Logos & Chartes graphiques vectorielles
  - Objets promotionnels & Tasses magiques thermosensibles
- **🔍 Lightbox & Fiche détaillée** : Vue agrandie de chaque création avec descriptif technique, matériaux et bouton de commande dédié.
- **💬 Intégration WhatsApp directe** : 
  - Bouton de contact flottant avec message pré-formaté
  - Envoi automatique de devis et demande d'informations directement sur WhatsApp Business
- **📱 Expérience Ultra-Responsive** : Design fluide et pensé Mobile-First pour une navigation irréprochable sur smartphones, tablettes et ordinateurs.
- **⚡ Performance & Animations** : Transitions douces propulsées par `motion` et un temps de chargement instantané grâce à Vite.

---

## 🛠️ Stack Technique

- **Frontend** : React 19, TypeScript
- **Styling** : Tailwind CSS v4
- **Animations** : Motion (`motion/react`)
- **Icônes** : Lucide React
- **Build Tool** : Vite 6

## 🚀 Installation et Lancement Local

Pour cloner et exécuter ce projet localement :

```bash
# 1. Cloner le dépôt
git clone https://github.com/votre-utilisateur/eliano-prime-print.git

# 2. Accéder au répertoire du projet
cd eliano-prime-print

# 3. Installer les dépendances
npm install

# 4. Démarrer le serveur de développement
npm run dev
