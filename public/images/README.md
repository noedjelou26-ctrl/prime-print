# Dossier d'images publiques

Vous pouvez déposer vos images directement dans ce dossier : `public/images/`.

### Utilisation dans l'application :
Toutes les images déposées ici sont directement accessibles via leur chemin web :
- Exemple : si vous ajoutez `affiche.jpeg` ici, son chemin d'accès sera `/images/affiche.jpeg`.
- Dans le code React / HTML : `<img src="/images/affiche.jpeg" alt="Mon image" />`
